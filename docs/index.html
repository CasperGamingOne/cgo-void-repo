Void Linux XBPS Native x86_64 / musl XLibre Compatible RSA Signed

⚡ Quick Installation

Step 1: Import Repository Public Key
Download and register the RSA verification key into XBPS trusted keys:
sudo wget -O /var/db/xbps/keys/cgo-void-repo.pem https://caspergamingone.github.io/cgo-void-repo/cgo-void-repo.pem
Step 2: Add Repository Source
Configure XBPS to fetch binary packages from this repository:
echo "repository=https://caspergamingone.github.io/cgo-void-repo/x86_64" | sudo tee /etc/xbps.d/50-cgo-void-repo.conf
Alternative: If you prefer GitHub Releases: repository=https://github.com/caspergamingone/cgo-void-repo/releases/latest/download
Step 3: Synchronize and Install
Update your XBPS index and install any available packages:
sudo xbps-install -S
sudo xbps-install -v <package-name>

🧩 Ecosystem & Compatibility

This repository is designed to coexist seamlessly with standard Void Linux and community repositories:

  • Official Void Repositories: Fully compatible with Void Linux standard, nonfree, and multilib trees.
  • XLibre (xlibre-void): Optimized and tested for systems running XLibre modular display server and drivers.
  • Third-Party Repos: Safe side-by-side operation with gsr4xbps, sonicde-void, and custom builds.
Security & Privacy: All packages are signed with RSA cryptography. Private signing keys are stored exclusively in isolated local storage or encrypted GitHub Secrets—never committed to the git tree.
