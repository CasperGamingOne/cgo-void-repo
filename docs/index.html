⚡ Quick Installation

1 Import Public Verification Key
Download and trust the official RSA signing key in your system's XBPS database:
sudo wget -O /var/db/xbps/keys/cgo-void-repo.pem https://caspergamingone.github.io/cgo-void-repo/cgo-void-repo.pem
2 Add Repository Source
Configure XBPS to fetch binary packages directly from this repository:
echo "repository=https://caspergamingone.github.io/cgo-void-repo/x86_64" | sudo tee /etc/xbps.d/50-cgo-void-repo.conf
Alternative: GitHub Releases source: repository=https://github.com/CasperGamingOne/cgo-void-repo/releases/latest/download
3 Synchronize & Install
Update your XBPS index and install any package from the catalog:
sudo xbps-install -S
sudo xbps-install <package-name>
