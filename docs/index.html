⚡ Quick Installation

1 Import Public Verification Key
Download and trust the official RSA signing key in your system's XBPS database:
sudo wget -O /var/db/xbps/keys/cgo-void-repo.pem https://caspergamingone.github.io/cgo-void-repo/cgo-void-repo.pem
2 Add Repository Source
Configure XBPS to fetch binary packages directly from the official GitHub Releases distribution:
echo "repository=https://github.com/CasperGamingOne/cgo-void-repo/releases/latest/download" | sudo tee /etc/xbps.d/50-cgo-void-repo.conf
3 Synchronize & Install
Update your XBPS index and install packages:
sudo xbps-install -S
sudo xbps-install <package-name>
